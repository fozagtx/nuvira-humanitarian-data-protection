# Brand — Nuvira

Status: active

Source: AO Agents design system (aoagents.dev UI study), applied to the Nuvira control room.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| background | `#0c0c09` | Warm near-black canvas |
| foreground | `#fbfbf9` | Warm white type |
| card | `#1d1d16` | Dark olive surfaces |
| muted | `#2b2b22` | Olive-gray fills |
| muted-foreground | `#abab9c` | Khaki body copy |
| border | `#ffffff1a` | Hairline (white 10%) |
| input | `#ffffff26` | White 15% |
| ring | `#7c7c67` | Focus |
| primary | `#e8e8e3` | Inverted pill buttons |
| primary-foreground | `#1d1d16` | Text on pills |
| brand | `#d25611` | Single accent (burnt orange) |
| brand-dark | `#9e400a` | Accent press |
| brand-light | `#e8804a` | Accent hover |
| destructive | `#ff6568` | Errors / critical |

One accent only. No emerald, no cool gray, no purple glow.

## Typography

- Sans: Geist, 100–900
- Mono: IBM Plex Mono 300/400/500 — eyebrows, hashes, labels
- Headlines: weight 400–500, tracking `-0.5px`, tight leading
- Eyebrows: 14px mono, tracking `0.5px`, muted-foreground

## Shape

- Buttons: `rounded-2xl` / `rounded-3xl` pills
- Cards: light radius, hairline border, no drop-shadow glow
- Status: small filled dots, not chips with pastels
